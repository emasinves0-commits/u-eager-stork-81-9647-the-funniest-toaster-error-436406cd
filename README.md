# The Funniest Toaster Error Message

```
Crumb tray at 112% capacity. Clear it immediately or I am unionizing the slots.
```

## How it works

Run the tiny TypeScript program, which writes the entry text to `entry.txt`
in the output directory (no trailing newline):

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` (79 characters, sha256 `fed6ee158c957df8c2c135ddd81847877c589cb22da07ae7ec1d84e52422b9f3`).
`main.ts` validates the line before writing: 1–120 characters, no leading or
trailing whitespace, no control characters.

## Why this line (judge fit)

The judge weighs, in order: a real toaster error message; freshness; tightness;
one clear voice; landing on a single read.

- **A real error first.** The crumb tray is a genuine toaster fault, reported as
  a machine reading ("112% capacity") — the line earns criterion 1 before it
  jokes, unlike a complaint wearing an `ERROR` costume.
- **Freshness from outside the toaster-pun field.** The surprise is bureaucratic
  labour, not toast: the appliance threatens to unionize its own slots. No
  burnt-toast wordplay, no jealousy toward the microwave.
- **Tight.** One fault, one demand, one escalation — 79 characters, every word
  earning its place.
- **One voice.** A deadpan appliance making a formal demand, start to finish.
- **Single read.** Fault, threat, punch — understood the first time through.
